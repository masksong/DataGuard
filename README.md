# DataGuard v3

Android 原生 Java 项目，目标 Android 6.0–8.0（minSdk 23 / targetSdk 26）。

## 功能
- 设置自然月移动流量上限（GB），默认 30.00 GB。
- 设置一个具体的强提醒值，精确到小数点后两位，默认 29.58 GB；该值必须小于月度上限。
- 达到强提醒值时触发高优先级通知、尝试播放系统默认闹钟铃声并重复震动。
- 达到月度上限时另行提醒。
- 查询系统 NetworkStatsManager 自然月统计；本地持久化设置和当月提醒状态。
- 前台服务后台监控，开机广播尝试恢复服务。

## 运行
1. Android Studio 打开项目，使用 JDK 17 和 Android SDK Platform 35。
2. 安装后授予电话权限与“使用情况访问权限”。
3. 设置月度上限，例如 30.00 GB；强提醒值例如 29.58 GB。
4. 点击“启动后台监控”，确认通知栏有常驻通知。

## 限制
- 本项目是源码原型，未声称已在真机编译/验证。双卡、厂商 ROM 和权限策略可能影响统计。
- 关机期间程序不运行；重启后开机广播会尝试恢复服务，但厂商省电策略可能阻止。
- 系统流量统计可能有延迟；自然月不一定与运营商计费周期一致。
- 通知渠道、勿扰模式、音量和厂商系统会影响铃声/震动。循环铃声并非所有系统都支持；本示例尝试循环闹钟铃声和重复震动。
- 普通未 Root APK 无法可靠自动关闭蜂窝数据；达到阈值只会提醒用户手动断开。
